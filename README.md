# 🐍 100 Days of Python

Welcome to my **#100DaysOfPython** challenge! 👋

This repository documents my journey of revisiting Python from the ground up with the goal of building a stronger foundation for **Data Engineering**. Over the course of 100 lessons, I'll strengthen my Python fundamentals before transitioning into real-world data engineering concepts such as file handling, APIs, databases, automation, and ETL pipelines.

This isn't just a collection of code—it's my personal Python handbook, containing notes, examples, exercises, challenges, and projects that I can revisit throughout my career.

---

# 📌 Why I'm Doing This

I've learned Python before, but like many developers today, I found myself relying on AI to generate code instead of writing it from scratch. While AI is an incredible productivity tool, I believe it should enhance my skills—not replace my understanding.

This repository is my commitment to revisiting Python fundamentals, strengthening my problem-solving abilities, and building the habit of writing code manually. By reinforcing the core concepts, I aim to use AI as a collaborator for faster development, debugging, and learning, rather than depending on it for every solution.

To make this journey structured and practical, I've divided this challenge into **two phases**.

### 🟢 Phase 1 — Python Fundamentals (Days 1–60)

The first phase focuses on revisiting and mastering Python fundamentals, including:

- Python Basics
- Variables & Data Types
- Strings
- Control Flow
- Loops
- Data Structures
- Functions
- Exception Handling
- Object-Oriented Programming

The goal is to build a strong foundation and regain the confidence to solve problems without relying on AI-generated code.

### 🚀 Phase 2 — Python for Data Engineering (Days 61–100)

Once the fundamentals are solid, the second phase shifts toward real-world Python applications used in Data Engineering, including:

- File Handling
- Modules & Packages
- Built-in Python Modules
- Regular Expressions
- Logging
- REST APIs
- SQLite
- NumPy
- Pandas
- ETL Pipelines
- Automation Scripts
- Final Projects

The objective is to bridge the gap between Python programming and practical data engineering workflows.

> **"Master the fundamentals first. Then let AI amplify your capabilities, not replace them."**

# 💡 Repository Philosophy

This repository is not about finishing a challenge as quickly as possible.

It's about building strong fundamentals, understanding *why* the code works, and developing the confidence to solve problems independently.

AI is an incredible tool, but true productivity comes from understanding the code you're writing. My goal is to become the kind of developer who can confidently write solutions from scratch and use AI to accelerate development—not replace critical thinking.

Every topic in this repository contains:

- 📖 Concept explanations
- 💻 Code examples
- 📝 Practice exercises
- 🚀 Challenge problems
- 📒 Personal notes

so that this repository becomes a long-term Python reference rather than just another collection of code snippets.
